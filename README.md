# Lara's Christmas Tree

A self-contained, picture-first 3D Christmas tree decorating app.

## Use it

Open `christmas-tree.html` in a modern browser. No build step, server, or install is required; Three.js is loaded from a CDN.

## Controls

- **Hand** (default): drag anywhere on the tree to rotate it, or tap the tree to add an ornament.
- **Move**: tap an ornament to select it, drag it along the tree to reposition it, or use the picture trash button to remove it.
- Use the tray to choose ornaments, and the magic ornament controls to describe and generate one.
- Pinch or scroll to zoom. The toolbar also toggles lights, falling snow, the treetop star, indoor/outdoor scenes, and shake.
- The picture button saves a PNG of the decorated tree.

Made for Lara, age 5.
